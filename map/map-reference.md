## 3. 제작과 글자층

- 내장 imagegen으로 기존 판화를 편집했다. 1차는 백화점 추가·기존 빈 라벨 판 제거, 2차는 백화점 옆 점선 보완이다. 실제 프롬프트 전문: `C:/Users/user/AppData/Local/Temp/dku-map-geo2/prompts.txt`.
- 최종 JPEG: 900×1300, 품질 83/100, 500,852 B. base64로 SVG에 내장했으며 SVG 전체는 673,815 B (상한 700,000 B)이다.
- 제목 `단국대학교 죽전캠퍼스 현장체험학습`, 부제 `TRAVEL LOG · 2026`, 랜드마크 8개 이름, 나침반 `북`의 총 11개 `<text>`를 사용한다. 이름은 config의 name과 문자 단위로 일치한다.
- 직전 판의 HCR Batang → Batang → 바탕 → AppleMyungjo → Nanum Myeongjo → Noto Serif CJK KR → serif 폰트 스택과 진한 갈색 명조를 유지한다. 8개 라벨은 모두 24px, 같은 양피지 그라데이션·접힌 모서리·테두리·상하 가는 선을 사용한다.
- 판 높이 40px, 너비는 Chromium 글자 경계 실측 폭 + 32px이다. 글자 좌우 여백 각각 16px, 상하 4px로 맞췄다. 그림에 있던 서로 다른 빈 판은 제거했다.
- `<g id="lm-…">` 8개에 `<title>`과 중심 좌표를 둔다. 외부 URL은 xmlns 외에 없고 외부 폰트·스크립트도 없다.
- 그림에는 간판 글씨·로고·거리·시간 숫자·금색 원·핀 표식을 넣지 않았다.

## 4. 검수 기록

- 최종 생성 그림 전체를 3개 구간으로 나누어 2배 확대 육안 확인: 문자·숫자·가짜 글리프 흔적 발견 0. 이는 시각 검수 결과이며 OCR에 의한 문자 부재 증명은 아니다.
- Chromium 151.0.7922.34에서 로컬 HTTP `<img>`로 정상 디코딩(900×1300). 전체 1장과 캠퍼스·카페거리/탄천/역/신세계·아트홀/나침반 확대 3장을 직접 확인했다.
- 라벨 8개 모두 판 안에 있다. 깨짐·잘림·라벨 간 겹침·오타 발견 0. DOM 측정: 양옆 16px(오차 0.001px 미만), 글자 겹침 0·캔버스 밖 0·pageerror 0.
- `node verify/checks.mjs --full`: 실행 결과는 `checks-full.txt`에 기록 후 확정한다.
- 배치: **박물관 < 도서관 < 정문 < 카페거리 < 신세계 < 죽전역 < 아트홀**. 카페거리 x=0.59 > 역 x=0.415, 아트홀 x=0.215 < 역 x=0.415. 모두 충족한다.
- 신세계 중심은 (0.335, 0.725)이다. 역 중심 (0.415, 0.78) 바로 위에 건물을 붙여 한 단지로 묘사했다. 물길은 백화점 위로 지나며 카페거리·신세계/역의 양쪽 기슭 관계를 유지한다.
- 기존 7곳 중심은 §1 표와 같고 그림 속 각 건물 안에 있다. 신세계 이외 기존 중심 좌표 변경 0. 다리 횡단 점선과 북쪽 바늘의 왼쪽 방향을 별도 육안 확인했다.
- F49의 항목명은 이전 지리 가정을 담고 있으며 문구 존재 여부를 검사한다. checks 통과를 지리 검증으로 간주하지 않고 실측표·배치·동선을 별도 확인했다. `verify/`는 수정하지 않았다.
- 지정한 `site/map/` 네 파일만 수정하며 커밋하지 않는다. 작업 전·후 비교는 `scope-review.json`에 저장한다.
